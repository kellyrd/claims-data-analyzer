A simple Python-based tool for loading, inspecting, and summarizing healthcare claims data. This project demonstrates foundational skills in data handling, CSV processing, and basic analytics using **pandas**.

---

## **Features**
- Loads claim data from a CSV file  
- Counts total number of claims  
- Identifies missing values across all columns  
- Prints a clean summary report to the console  

---

## **Tech Stack**
- Python 3.13  
- pandas  

---

## **How to Run**
1. Clone the repository  
2. Install dependencies:  
   ```bash
   pip install pandas
3. Run the script:
   python main.py
